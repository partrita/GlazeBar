======================================================================
  GlazeBar + GlazeWM 커뮤니티 설치 프로그램 (Community Bundle)
======================================================================

[설치 전 확인 사항]
• 실행 중인 GlazeWM 또는 GlazeBar가 있다면 미리 종료해 주세요.
• 기존 커뮤니티 번들이 설치되어 있다면 이전 버전을 제거한 후 설치를 진행해 주세요.
• 기존 설정 및 파일은 설치 중 자동으로 안전하게 백업됩니다.

[주요 설치 경로]
• 프로그램 설치 위치 : %USERPROFILE%\.glzr\glazewm
• 사용자 설정 백업   : %USERPROFILE%\.glzr\community-backups

[핵심 안내]
1. Visual C++ 런타임:
   필요 시 Microsoft 공식 서버에서 서명된 정품 런타임을 안전하게 내려받아 설치합니다.
2. 윈도우 시작 시 자동 실행:
   다음 설정 화면에서 자동 실행 여부를 체크 박스로 손쉽게 지정할 수 있습니다.
3. 안정성 개선:
   창 이동 시 발생하던 포커스 오류(No workspace focused 등)가 수정되었습니다.
4. 삭제 및 복원:
   제거 시 'Windows 설정 > 설치된 앱'에서 삭제할 수 있으며, 기존 설정이 자동으로 원상 복원됩니다.

----------------------------------------------------------------------
[English Summary]
• Community bundle installing GlazeBar and optimized GlazeWM.
• Please close any running GlazeWM/GlazeBar instances before proceeding.
• Existing configurations will be automatically backed up to %USERPROFILE%\.glzr\community-backups.
• Windows Auto-start option is available in the next task selection page.
• Complete sources, license notices (GPL-3.0-only), and documentation are located in the installation folder.
